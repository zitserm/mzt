Tips

  • Hold the phone directly above the track, parallel to the ground.
  • Put the reference object flat, next to the track, at the same depth.
  • Length and width are measured from the points you tap, so take care to hit the edges.
  • This uses the photo only (the iPhone 11 has no LiDAR), so accuracy is roughly within a few millimetres.
